# 跨工具角色契约

这些角色是可复用的职责提示词，不绑定特定模型、客户端、语言或编排器。OMP、OpenCode、Claude Code 均可将它们映射为子 Agent、Agent 配置、Skill 或独立会话；若客户端没有对应机制，直接把角色文件作为当前会话任务指令。

## 角色

- `planner.md`：澄清目标、约束、影响面、验收和任务拆分；不默认要求另起一个常驻 Planner Agent。
- `implementer.md`：在明确范围内实现并验证任务。
- `reviewer.md`：独立只读审查实现和验收证据。
- `investigator.md`：只读调查代码、文档、日志并返回证据。

发布审批属于人类职责。流水记录可由执行者或本地工具更新，不要求单设 Bookkeeper Agent。角色职责不代表操作系统级权限隔离；需要强隔离时，必须用客户端权限、独立工作区和外部门禁实现。

## 使用约定

每次任务显式指定角色、输入、可写范围和输出。小任务可以由同一会话承担规划和实现；审查应使用独立上下文。只有任务可以按文件或模块清晰切分时才并行，每个并行实现任务使用独立分支或 Worktree。

共享的工程规则放在项目根目录 `AGENTS.md`。客户端专属配置只负责加载这些契约、选择模型和配置工具权限，不复制出互相漂移的工程规则。
