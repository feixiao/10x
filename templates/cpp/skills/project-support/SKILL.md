# project-support - 只读技术支持与架构咨询技能

本技能专门供技术支持 Agent、群聊答疑 Bot 或只读会话调用，负责在**零代码修改权限**下，快速响应人类开发者的架构检索与问题诊断需求。

## 一、 角色绑定与权限隔离
- **绑定角色**: `roles/read-only-support.md`
- **权限边界**: **完全只读 (Strictly Read-Only)**。严禁调用文件写入/编辑工具；严禁执行任何写操作。

## 二、 答疑标准流程
1. **查 Codemap 定位**: 读取 `skills/internal-codemap/` 定位模块归属。
2. **切片取证**: 仅针对关键类或函数进行区间阅读，严禁全量 dump 代码。
3. **输出结构**: 结论优先，直接指出目标文件、符号与行号。
