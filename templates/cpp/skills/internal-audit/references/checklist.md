# C++ 盲审技术栈核查清单 (checklist.md)

- [ ] **生命周期错配**: 是否存在返回栈上对象指针/引用、`string_view` 指向已销毁临时对象？
- [ ] **拷贝与移动**: 新增类若包含裸资源句柄，是否已显式 `delete` 或正确实现拷贝构造与移动赋值？
- [ ] **跨线程安全性**: 传递给其他线程的数据是否为深拷贝或受锁保护？严禁裸指针穿越线程。
- [ ] **缓冲区与越界**: 缓冲区访问（Buffer Index）是否有边界守卫？整型运算是否可能下溢？
- [ ] **异常与早期返回**: 动态申请的内存/FD 在所有 early return 分支中是否均能安全析构？
